# Velkris

## Secure Supervisory Multi-Agent LLM Engineering Copilot for Software-Defined Vehicles

AutoMind is an enterprise-style automotive AI engineering platform designed for software-defined vehicle teams.

It helps engineers securely analyze requirements, safety reports, vehicle logs, code, documents, and project decisions using private RAG, multi-agent supervision, memory, evaluation, authentication, and monitoring.

## Core Features

- Secure project-based authentication and RBAC
- Private RAG for automotive documents
- Requirement intelligence agent
- Test engineering agent
- Safety reasoning agent
- Vehicle log analysis agent
- Context-aware code engineering agent
- Supervisory multi-agent orchestrator
- Engineering knowledge graph
- Impact and root cause analysis
- LLM evaluation lab
- Audit logs and monitoring
- Docker-based deployment

## Tech Stack

- Frontend: React + TypeScript + Tailwind CSS
- Backend: FastAPI
- Database: PostgreSQL
- Vector Database: ChromaDB
- Cache: Redis
- Monitoring: Prometheus + Grafana
- Deployment: Docker, AWS EC2
